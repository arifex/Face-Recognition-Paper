## Overview

This notebook compares classical and deep-learning face recognition on the small Olivetti faces benchmark (40 people, 10 images each):

| # | Method | Split | Key settings |
|---|---|---|---|
| 1 | **Eigenfaces** (PCA + nearest neighbour) | 300 / 100 | eigenfaces via the M × M covariance trick, K = 1…80 |
| 2 | **SVM** (RBF, linear, polynomial) | 320 / 80 | C = 10⁻³ … 10³, `gamma='scale'`, one-vs-one |
| 3 | **Neural network** (dense 256-128-128 + dropout) | 320 / 80 | Adam 0.001, 100 epochs, batch 128, ReduceLROnPlateau |
| 4 | **Transfer learning** (frozen ImageNet MobileNet) | 320 / 80 | GAP → Dense 1024 → Dense 40, Adam 0.0004, 100 epochs, batch 64 |

A final section re-evaluates the classical methods with **stratified 5-fold cross-validation**, because single-split accuracy on 80 test images moves in steps of 1.25 points.

## Dataset

**Olivetti faces** (also called the ORL / AT&T face database), AT&T Laboratories Cambridge, 1992–1994. It has 400 grey-scale images of 40 subjects, each 64 × 64 pixels with values in [0, 1], under varying lighting, expressions and facial details.

- `data/olivetti_faces.npy`: images, shape (400, 64, 64)
- `data/olivetti_faces_target.npy`: subject labels 0–39, shape (400,)

These arrays are the same data scikit-learn provides through `sklearn.datasets.fetch_olivetti_faces()`, which the notebook uses as a fallback. The database is freely available for research use. Please acknowledge AT&T Laboratories Cambridge when you use it.

## Results

Test accuracy with `random_state = 42`:

| Method | Test accuracy (%) | 5-fold CV (%) |
|---|---|---|
| Eigenfaces (best K = 20) | 90.00 | 92.75 ± 2.42 |
| SVM (RBF, C ≥ 10) | 96.25 | 96.50 ± 1.22 |
| **SVM (linear)** | **97.50** | **97.50 ± 0.79** |
| SVM (polynomial) | 97.50 | 96.50 ± 1.84 |
| Neural network (3 dense layers) | 80.00 | – |
| Transfer learning (MobileNet) | *see notebook output* | – |

Exact numbers can differ slightly with library versions and hardware, especially for the neural models.

**Takeaway:** with only 10 images per person, linear SVMs and eigenfaces match or beat deep models. A dense network trained from scratch overfits, and transfer learning from ImageNet recovers most of the gap.

## How to run

**Google Colab (recommended)**
1. Click the **Open in Colab** badge above.
2. Go to **Runtime → Change runtime type → T4 GPU**.
3. Click **Runtime → Run all**. The dataset loads automatically, and the full run takes about 5 minutes on a GPU.

**Locally**
```bash
git clone https://github.com/arifex/Face-Recognition-PCA-SVM-MobileNet.git
cd Face-Recognition-PCA-SVM-MobileNet
pip install -r requirements.txt
jupyter notebook Face_Recognition.ipynb
```
